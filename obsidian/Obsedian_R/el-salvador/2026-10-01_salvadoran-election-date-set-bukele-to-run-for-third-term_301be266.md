# Salvadoran election date set, Bukele to run for third term

> **Source:** Latin America Daily Briefing  
> **Published:** 2026-10-01  
> **URL:** https://latinamericadailybriefing.substack.com/p/salvadoran-election-date-set-bukele

## Summary

The Supreme Electoral Tribunal set February 28, 2027, for El Salvador’s presidential election, in which Bukele is expected to run for a third term. The article highlights reforms creating six-year presidential terms, eliminating runoffs, and permitting indefinite re-election.
